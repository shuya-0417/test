# X 投稿文リスト

自動投稿・自動通知の仕組みは使わない。`content/queue.jsonl` に、Xへ投稿する文章がそのまま並んでいるだけ。上から順に、自分のペースで手動でXに投稿する。

## 使い方

1. `content/queue.jsonl` を開く（1行1件、上から順）
2. 投稿した行の文章をコピーしてXに貼って投稿する
3. 投稿し終わった行は消してもいいし、印をつけて残してもいい（自由）

`text` が配列になっている行は、スレッド（連続投稿）用の複数ツイート。

```jsonl
{"text": "単発ツイートの例文"}
{"text": ["スレッド1件目", "スレッド2件目", "スレッド3件目"]}
```
